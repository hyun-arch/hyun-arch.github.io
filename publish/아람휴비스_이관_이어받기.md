## 어디까지 했나

원고 24편 중 **4편**을 `blog.naver.com/aramhuvis` 로 옮겨 예약 발행까지 걸었다.

| 글 | 예약 |
|---|---|
| 2026-10-17-두피진단기-원리 | 10-25 06:30 |
| 2026-10-22-환절기피부 | 10-25 16:30 |
| 2026-10-18-두피유형-4가지 | 10-25 06:30 ← 겹침 |
| 2026-10-22-각질피부 | 10-25 16:30 ← 겹침 |

뒤 2편이 겹친 이유: 시·분만 맞추고 **날짜 칸을 안 건드렸다.** 지금은 고쳤다.

## 이어서 할 것

```bash
ego-browser nodejs < publish/aramhuvis-move.mjs
```

- 진행 상태는 `/tmp/aramhuvis-done.json` (사본: `publish/.aramhuvis-done.json`).
  없으면 사본을 `/tmp` 로 되돌려 놓고 돌릴 것. 안 그러면 4편을 또 올린다.
- 남은 20편. 예약은 끝낸 수만큼 자리를 건너뛴다.
- 겹친 2편의 예약 시각은 네이버 「예약 발행」 목록에서 손으로 고치면 된다.

## 막혀 있는 것 — 이안사랑 썸네일 29편

표지 29장은 다 만들어 뒀다 (`naver-blog/posts/*/cover.png`, `naver-blog/covers-old/*.png`).
240px 에서 읽히는 것도 확인했다 (`~/Desktop/썸네일_240px_확인.png`).

**못 하는 이유는 계정이다.** ego lite 에 로그인된 네이버 계정이 아람휴비스 하나뿐이라
`blog.naver.com/ianlove80/postwrite` 로 가면 `blog.naver.com/aramhuvis` 로 튕긴다.
로그인을 다시 하는 문제가 아니라 **계정을 추가해야 하는 문제**다.
사람이 브라우저에서 ianlove80 을 추가로 로그인해 주면 `publish/cover-run.mjs` 로 한 번에 돈다.

## 이번에 알아낸 것 (새 글쓰기 화면 = iframe 없는 postwrite)

| | |
|---|---|
| 본문 컨테이너 | **`.se-canvas`** — `.se-main-container` 는 **없다** |
| 제목·본문 입력 | 숨은 버퍼. 좌표 클릭 후 `keyboard.type()` |
| 예약 라디오 | `#radio_time2` 를 **좌표로** 눌러야 켜진다. JS `click()` 은 React 가 안 받는다 |
| 날짜 | `input.input_date__UwKAB` 는 readonly. 눌러서 뜨는 **jQuery UI 달력**(`.ui-datepicker`)에서 고른다. 달 넘김은 `.ui-datepicker-next/prev`, 날짜는 `.ui-state-default` |
| 시·분 | 보이는 `<select>` 2개 (시 00~23 / 분 00,10,…,50) |
| 발행 | `button[data-click-area="tpb.publish"]` → `tpb*i.publish` |

`.se-main-container` 를 단독으로 쓰던 곳은 전부 `.se-content, .se-canvas, .se-main-container` 폴백으로 고쳤다
(`publish/fix-link.mjs`, `publish/lib/channels/naver.mjs`, `publish/inspect-posts.mjs`, `naver-blog/setup/중복.mjs`).
