# 발행 — 한 번 쓰면 모든 곳으로

사진이든 영상이든 한 줄이든, **한 번만 올리면 채널마다 알맞게 고쳐서 내보냅니다.**
글자 수, 해시태그 개수, 링크를 받는지 여부가 채널마다 달라서 그 처리를 여기가 대신합니다.

## 세 가지 쓰는 법

**1. 폴더에 던져 넣기 (가장 편함)**

```bash
node publish/watch.mjs          # 켜 두면 계속 지켜봅니다
```

`publish/queue/` 에 파일을 넣으면 알아서 올라갑니다.

- `오늘한컷.jpg` + `오늘한컷.txt` → 사진 + 그 설명글
- `릴스.mp4` + `릴스.txt` → 영상 + 설명
- `생각.md` 하나만 → 글만

올린 뒤엔 `publish/sent/날짜/` 로 옮겨집니다.

**2. 명령 한 줄**

```bash
node publish/post.mjs --text "오늘 한 줄" --to all
node publish/post.mjs --media 사진.jpg --text "설명" --tags 경영,AI
node publish/post.mjs --media 쇼츠.mp4 --title "제목" --to youtube,instagram,tiktok
```

**3. 보내기 전에 확인**

```bash
node publish/post.mjs --status     # 어디가 준비됐는지
node publish/post.mjs --preview --text "…" --media 사진.jpg   # 채널별로 어떻게 나갈지
node publish/post.mjs --dry ...    # 실제로 안 보내고 시험
```

### X — 기본에서 뺐습니다

2026년 2월부터 무료 등급이 없어져 건당 과금입니다. `--to all` 에서는 **나가지 않습니다.**
필요할 때만 `--to x` 로 이름을 직접 적어야 나갑니다.

### 네이버 블로그 — 브라우저로 뚫었습니다

공개된 글쓰기 API 가 없어서, **사람이 하는 일을 그대로 대신합니다.** 브라우저로 글쓰기 창을
열고 제목·본문을 쓰고 사진을 붙이고 발행을 누릅니다.

```bash
node publish/naver-open.mjs        # 처음 한 번만 — 평소처럼 로그인
node publish/post.mjs --text "…" --to naver
```

로그인은 `publish/.browser` 프로필이 평소 크롬처럼 들고 있습니다. **비밀번호도 쿠키도 저장하지 않습니다.**
화면이 바뀌어 버튼을 못 찾으면 `NAVER_HEADLESS=0` 으로 돌려 눈으로 보면서 고치면 됩니다.

> 네이버는 자동화를 권장하지 않습니다. 내 계정으로 내 글을 올리는 용도로만 쓰시고,
> 짧은 시간에 몰아서 올리지 마세요.

> 인스타그램은 글만 못 올립니다(사진·영상 필수). 유튜브·틱톡은 영상만 받습니다.
> X 는 한글을 2자로 세기 때문에 280자가 실제로는 한글 140자입니다 — 알아서 줄여 보냅니다.

## 맥이 꺼져 있어도 돕니다 — 깃허브가 대신 돌림

`.github/workflows/publish.yml` 이 저장소 안에서 발행을 돌립니다.
**공개 저장소라 실행 시간이 무료**입니다(사설 저장소만 분당 과금).

- `publish/queue/` 에 파일을 **커밋해서 올리면** 그 즉시 발행
- 그것과 별개로 **10분마다** 큐를 확인
- Actions 탭에서 **손으로 실행**해 글 한 줄만 올리는 것도 가능

토큰은 저장소 **Settings → Secrets and variables → Actions** 에 넣습니다.
`.env` 파일은 절대 커밋되지 않습니다.

> 공개 저장소라 `publish/queue/` 에 올린 파일은 발행 전에도 보입니다.
> 남에게 보이면 안 되는 초안은 큐에 넣지 말고 로컬에서 `post.mjs` 로 보내세요.
> 깃허브는 저장소가 60일간 조용하면 예약 실행을 멈춥니다 — 매일 쓰면 상관없습니다.

## 사진·영상은 어떻게 올라가나

메타(스레드·인스타)와 틱톡은 파일을 직접 안 받고 **공개 주소**를 요구합니다.
그래서 이 저장소가 이미 쓰던 방식을 자동화했습니다 — 파일을 `gh-pages` 브랜치의 `/sns/` 로 올리고
`https://hyun-arch.github.io/sns/…` 주소를 만들어 넘깁니다. 따로 이미지 호스팅을 붙일 필요가 없습니다.

## 토큰 받기가 제일 귀찮습니다 — 그걸 줄였습니다

```bash
node publish/youtube-connect.mjs <클라이언트ID> <보안비밀>   # 브라우저 열림 → 허용 → 토큰 출력
node publish/meta-check.mjs <액세스토큰>                      # 내 페이지·인스타 ID·권한·만료일 한 번에
```

`meta-check` 는 지금 가진 메타 토큰으로 **무엇이 되고 무엇이 모자란지** 알려주고,
`FB_PAGE_ID`·`IG_USER_ID` 를 찾아서 그대로 붙여넣을 수 있게 뽑아 줍니다.

## 준비하기

```bash
cp publish/.env.example publish/.env   # 값을 채우세요
```

**먼저 무료 4곳**(텔레그램·블루스카이·디스코드·마스토돈)을 붙이세요. 다 합쳐 10분이면 되고
심사가 없어서 오늘 바로 자동 발행이 돕니다. 메타 계열과 유튜브는 승인에 며칠 걸립니다.

`publish/.env` 와 `publish/sent/` 는 git 에 올라가지 않습니다.
