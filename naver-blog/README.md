# 네이버 블로그 — 좋은 글을 매번 지키는 장치

스폰지클럽 8회차 케이(엘리아 세레니티) 발표 **"좋은 글을 매번 지키는 장치"** 를 분석해
아람휴비스 상황에 맞게 다시 만든 것입니다.

## 바탕이 되는 생각

> **수익 = 노출 × 클릭 × 링크클릭 × 결제 × 건당가 × 수수료**
> 앞의 두 칸(노출·클릭)은 **글이 정한다.** 여기서 막히면 뒤가 아무리 좋아도 0이다.

그래서 이 도구는 전부 "좋은 글"을 위한 것입니다. 사람이 들어오고, 읽고, 누르게 만드는 글.

> **AI한테 매일 시키지 말고, 일하는 프로그램을 한 번 만들어라.**
> 매일 AI에 시키면 돈이 들고 결과도 매번 다르다.
> 판단이 필요한 자리만 AI, 나머지는 정해진 규칙.

## 장치 넷

| 장치 | 하는 일 | 외부 API |
|---|---|---|
| **키워드 저울** | 글감을 체급·트렌드·시즌·황금 네 기준으로 단다 | 네이버 3종 (무료) |
| **검사** | 내 기준을 글이 지켰는지 본다 | **없음** |
| **AI 작가** | 초고를 쓰고, 검사에 걸리면 고쳐 쓴다 | **없음** (Claude Code) |
| **발행** | 검사를 통과한 글만 올린다 | 없음 (브라우저) |

## 쓰는 법

```bash
# 글감이 쓸 만한지
node naver-blog/blog.mjs 저울 "두피진단기 가격" --검색 1900 --경쟁 8400 --시즌 2.5

# 초고 쓰기 (검사·고쳐쓰기까지 자동)
node naver-blog/blog.mjs 쓰기 "두피진단기 원리" \
  --사실 facts.json --링크 "https://www.aramhuvis.com/ko" --각도 "처음 보는 사람 눈높이"

# 검사만
node naver-blog/blog.mjs 검사 posts/2026-10-17-두피진단기-원리

# 발행 (검사 통과한 글만)
node naver-blog/blog.mjs 발행 posts/2026-10-17-두피진단기-원리

# 지금 내 기준
node naver-blog/blog.mjs 기준
```

## 키워드 저울 — 네 가지 기준

| 기준 | 묻는 것 |
|---|---|
| **체급** | 내가 이길 수 있는 크기인가 (경쟁 글 ≤ 내 기준선) |
| **트렌드** | 지금 네이버에서 뜨는가 |
| **시즌** | 작년 이맘때 곡선이 오르는가 |
| **황금** | 찾는 사람에 비해 글이 적은가 |

**체급이 가장 중요합니다.** 강의의 실제 사례:

| 키워드 | 월 검색 | 경쟁 글 | 유입 |
|---|---|---|---|
| 부산가볼만한곳 | 175,500회 | 2,318,551개 | **0명** |
| 쌍곡예그리나펜션 | 560회 | 189개 | **27명** |

큰 키워드를 노리는 게 아니라 **내가 1페이지에 들어갈 수 있는** 키워드를 고르는 일입니다.

기준선은 남의 숫자가 아니라 **내 블로그 실측**입니다 —
"내 글이 실제로 10위 안에 들었던 키워드 중 경쟁 글이 가장 많았던 수".
`data/standards.json` 에 있고, 밤 루틴이 매일 고쳐 씁니다.

## 검사가 보는 것

**네이버**
제목 25~40자 · 제목·첫문단에 키워드 · 키워드 밀도 1.2~2.2% · 본문 1700~2500자 ·
이미지 5장 이상 · 소제목 4개 이상 · 링크 1개 이상

**구글·AI 검색 (GEO·AIO)**
질문형 소제목 2개 이상 · 소제목 바로 밑 40~220자로 **답 먼저** —
AI 검색이 인용하는 모양입니다.

**지뢰**
과장 표현(최고·100%·보장…) 차단 · **의료 표현(치료·효능·완치…) 차단** —
아람휴비스는 진단기기 회사라 의료기기법 위험이 있습니다 ·
`facts.json` 에 없는 숫자는 못 쓰게 막습니다

## 외부 API 없이 되나

| 부분 | 독립 가능 |
|---|---|
| 검사 | **완전히 됩니다.** 인터넷도 필요 없습니다 |
| AI 작가 | **됩니다.** 구독 중인 Claude Code 를 부릅니다. 추가 비용 0 |
| 발행 | **됩니다.** 브라우저 자동화 (네이버는 공개 글쓰기 API 가 없습니다) |
| 키워드 저울 | **숫자는 네이버에서 와야 합니다.** 월 검색량·경쟁 글 수는 만들어낼 수 없습니다 |

키워드 저울만 네이버 공식 API 3종이 필요하고, **셋 다 무료**입니다.

- 검색광고 API — 월 검색량
- 검색 API — 경쟁 글 수
- 데이터랩 API — 트렌드·시즌

지금은 숫자를 직접 넣어도(`--검색 --경쟁`) 돕니다. API 키를 넣으면 자동으로 받아옵니다.

## 사람이 하는 일

강의의 마지막 장이 이렇게 끝납니다.

> 장치는 내 기준을 기억하는 그릇이다. 기계는 까먹지 않을 뿐이다.
> **무엇을 쓸지 고르는 눈과 마지막 발행 버튼은 사람 몫이다.**

그래서 `발행` 은 자동으로 돌지 않습니다. 검사를 통과한 글만, 사람이 눌러야 올라갑니다.
