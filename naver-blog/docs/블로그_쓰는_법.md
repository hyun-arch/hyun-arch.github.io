# 블로그 쓰는 법 — 혼자 쓸 때 보는 가이드

> 2026-10-24 · 이안사랑 블로그 24편을 올리면서 실제로 겪은 것만 적었다.
> 이론이 아니라 **네이버에서 걸린 것·안 걸린 것**이다.

---

# 0. 먼저 — 글 한 편의 뼈대

글을 쓰기 전에 **이 다섯 줄을 먼저 채운다.** 못 채우면 아직 쓸 글이 아니다.

| 칸 | 예시 (「두피 냄새」 글) |
|---|---|
| 누가 읽나 | 아침에 감았는데 오후에 냄새 나서 검색하는 사람 |
| 뭘 검색하나 | 「두피 냄새」 「머리 냄새 원인」 |
| 어떤 오해를 깨나 | 「안 감아서 나는 거다」 → 아니다, 유분이 변해서다 |
| 읽고 나면 뭘 하나 | 밤에 감고 완전히 말린다 |
| 내가 왜 말할 자격이 있나 | 두피를 22년 측정해 온 회사 |

마지막 칸이 **제일 중요하다.** 이게 없으면 어디서 본 글을 옮긴 것처럼 읽힌다.

# 1. 기승전결 — 네이버에서 실제로 통한 구조

## 전체 틀

```
제목            25~40자 · 검색어를 앞에, 상황을 뒤에
───────────────────────────────
[기] 도입       2~3문장 · 독자의 장면으로 시작
     표지 이미지
[기] 선언       "이 글은 ○○한 입장에서 …를 정리했습니다"
───────────────────────────────
[승] 왜 그런가?          ← 질문형 소제목
     답을 먼저 한 문장
     설명 2~3문장
     카드 이미지
[승] 왜 ○○하면 안 되나?
     …
───────────────────────────────
[전] 무엇부터 하면 되나?   ← 행동
     ① ② ③ 로 끊어서
[전] 나는 어느 쪽일까?     ← 측정으로 넘어가는 다리
     느낌으로는 안 갈린다 → 재 보면 갈린다
     내부 링크 1~2개
     제품/서비스 링크 1개
───────────────────────────────
[결] 정리                 ← 불릿 4~6줄
```

## 각 부분에서 지킬 것

### [기] 도입 — 첫 두 줄에서 결판난다

**사람의 장면으로 시작한다.** 정의로 시작하면 바로 닫는다.

> ✗ 「두피 냄새란 두피에서 발생하는 불쾌한 냄새를 말합니다.」
> ✓ 「분명 아침에 감았는데 오후가 되면 두피에서 냄새가 납니다. 손으로 쓸어 보면 더 확실합니다.」

**그리고 바로 오해를 집는다.** 독자가 믿고 있는 것을 먼저 건드려야 끝까지 읽는다.

> 「감는 횟수를 늘려도 그때뿐입니다. 두피 냄새는 "안 감아서"가 아니라, 다른 원인이 있는 경우가 많습니다.」

### [승] 소제목은 **질문으로**

AI 검색(ChatGPT·퍼플렉시티)이 인용할 때 **질문형 소제목 + 바로 아래 한 문장 답**을 통째로 가져간다.

> ✓ `## 두피 냄새는 왜 날까요?`
> ✗ `## 두피 냄새의 원인`

소제목 **바로 밑 첫 문장이 답**이어야 한다. 배경 설명부터 하면 인용이 안 된다.

> 「주된 원인은 **유분의 산패**입니다. 두피에서 나온 유분이 공기·세균과 만나 시간이 지나면 냄새로 바뀝니다.」

### [전] 행동은 번호로, 측정은 다리로

읽고 나서 **오늘 할 수 있는 것**이 있어야 한다. ①②③ 으로 끊는다.

그다음에 「나는 어느 쪽일까」를 넣는다. 이게 **제품으로 가는 다리**다.

> 「눈으로는 헷갈립니다. 지성인데 건조하다고 느끼는 경우도 많습니다.
>  재 보면 어느 쪽에 가까운지 나와, 방향이 정해집니다.」

광고처럼 안 들리는 이유는 **앞에서 이미 쓸모를 줬기 때문**이다. 공짜로 줄 걸 먼저 다 주고 나서 말한다.

### [결] 정리는 불릿 4~6줄

읽은 사람이 **스크롤만 내려서 다시 볼 자리**다. 문장을 줄이지 말고 결론만 남긴다.

> · 두피 냄새의 주원인은 **유분의 산패**, 여기에 땀·세균·덜 마른 두피가 겹칩니다
> · 감아도 나는 건 **헹굼 부족·유분 과다·덜 마름** 때문인 경우가 많습니다

# 2. 사람이 쓴 것처럼 — 기계 티가 나는 지점들

AI 가 쓴 티는 **내용이 아니라 문장 습관**에서 난다.

## 바로 들키는 것

| 기계 티 | 사람 티 |
|---|---|
| 「~하는 것이 중요합니다」 반복 | 「~합니다」 「~입니다」 로 끊기 |
| 「첫째, 둘째, 셋째」 | 「①」 또는 그냥 줄바꿈 |
| 「본 포스팅에서는」 | 「이 글은」 |
| 모든 문단이 3~4문장으로 균일 | 한 줄짜리 문단을 섞는다 |
| 「놀라운」 「완벽한」 「최고의」 | 숫자나 구체적 상황 |
| 결론이 「~해 보시기 바랍니다」 | 「~하는 편이 낫습니다」 |

## 사람 티가 나는 다섯 가지

**① 숫자를 센다**
> 「검지 한 마디 길이」 「거품이 사라진 뒤에도 30초 더」 「4~8주」

**② 실패를 적는다**
> 「비듬 샴푸를 쓰는데 더 심해졌다」는 말이 여기서 나옵니다.」

**③ 안 되는 것을 말한다**
> 「솔직히 말하면, 타고난 모공 크기를 영구히 줄이기는 어렵습니다.」
> **이 한 줄이 글 전체의 신뢰를 만든다.**

**④ 조건을 단다**
> 「대부분은」 「~인 경우가 많습니다」 「다만 두 경우는 다릅니다」

**⑤ 돈 안 드는 것부터 말한다**
> 「제품을 바꾸기 전에 베개 커버·수건·물 온도를 2주만 손봐도 달라지는지 보입니다.」

## 문장 길이를 섞는다

기계는 길이가 고르다. 사람은 들쭉날쭉하다.

> 「유분을 강하게 걷어 낼수록 두피는 더 많이 분비합니다. 그래서 감은 지 얼마 안 돼 다시 기름집니다. **겉은 기름지고 속 두피는 당기는 것입니다.**」

짧은 문장 하나를 일부러 끼운다.

# 3. 방문자를 늘리는 법 — 네이버에서 실제로 먹힌 것

## 제목 — 25~40자

| | |
|---|---|
| **앞** | 검색어 그대로 (「두피 냄새」 「선크림」) |
| **뒤** | 독자의 상황 (「아침에 감았는데 오후만 되면 나는 이유」) |

**검색어를 쪼개지 않는다.** 「두피의 냄새」 말고 「두피 냄새」. 사람들이 치는 대로 쓴다.

제목 두 개를 놓고 고를 때는 **내가 검색창에 뭘 칠까**로 고른다.

## 분량 — 본문 1,700~2,500자

네이버는 체류 시간을 본다. 1,000자는 짧고, 3,000자는 중간에 닫는다.

**채우려고 늘리지 않는다.** 늘릴 거면 **실제로 궁금한 것**을 더한다.

> 「선크림을 얼마나 발라야 표시된 지수가 나오나」 ← 다들 궁금한데 아무도 안 적는 것

## 이미지 — 5장 이상, 소제목마다 하나

글만 있으면 내려가다 닫는다. **소제목 밑마다 한 장**이 기준이다.

그림에 **그 소제목과 답을 적어 둔다.** 그림만 넘겨도 요지가 남으면 저장·공유가 붙는다.

## 썸네일 — 앨범형에서 240px로 줄어든다

**제목 전체를 넣으면 안 읽힌다.** 짧은 후킹 문구를 크게 넣는다.

```
윗줄  모공            ← 주제 (6~8자)
아랫줄  왜 넓어 보일까   ← 질문 (8~12자)
```

합쳐 14자 안쪽, 글자는 캔버스 1080px 기준 **130px 이상**.

## 내부 링크 — 글끼리 엮는다

글 하나가 다른 글 **1~3개**를 가리키게 한다. 체류가 늘고 색인이 빨라진다.

> 「유형이 궁금하면 [두피유형 4가지]를 함께 보세요.」

**반드시 그 글의 진짜 주소로 건다.** 블로그 홈으로 걸면 독자가 못 찾는다.

## 발행 시각 — 오전 6:30 · 오후 4:30

출근 전과 퇴근 전. **하루에 몰아 올리지 않는다.** 두 편이 있으면 두 자리에 나눠 넣는다. 같은 글 수로 노출이 두 번 생긴다.

## 태그 — 5~8개

제목에 못 넣은 검색어를 태그로 넣는다. 20개씩 넣으면 오히려 저품질로 본다.

## 하지 말 것 (저품질 신호)

- 「최고」 「1위」 「유일한」 「100%」 「완벽」 「보장」 「무조건」
- 화장품 글에 **「치료」 「효능」 「완치」 「질환」 「처방」** — 광고법·의료기기법 위험
- 같은 내용을 제목만 바꿔 재발행
- 본문에 마크다운 기호(`##` `**`)가 그대로 남는 것

# 4. 수익화 — 글을 망치지 않고 넣는 법

## 원칙 하나

**독자가 이미 이득을 봤을 때만 링크를 꺼낸다.**

글의 **70%가 지난 뒤**, 그러니까 「나는 어느 쪽일까」 다음 자리다. 그 앞에 넣으면 광고 글이 되고 이탈한다.

## 자리와 형태

```
[전] 나는 어느 쪽일까?
     ← 여기서 측정·진단 이야기 (공짜 쓸모의 마지막)

     릴라이 공식몰 → lilai.ai        ← 링크 ①  (브랜드)
     https://lilai.ai

[결] 정리
     …
     ※ 이 글에서 쓴 ○○는 아래에서 받을 수 있습니다  ← 링크 ② (다운로드·제휴)
```

## 형태별로 다르게

**① 자사 제품·서비스** — 설명 한 줄 + 주소 한 줄
> 「메디커스텀은 그 측정 관점에서 손상 손을 위한 보습을 설계했습니다 → medicustom.co.kr」
> 「사세요」가 아니라 **「그래서 이렇게 만들었습니다」**로 쓴다.

**② 다운로드(체크리스트·가이드)** — 글의 요약을 주는 형태가 가장 잘 받는다
> 「두피 유형 자가점검표를 PDF로 정리해 두었습니다 → (링크)」
> 글을 읽은 사람이 **그 자리에서 쓸 것**을 준다.

**③ 어필리에이트(제휴 링크)** — 세 가지를 지킨다
- **글 하나에 한두 개.** 많으면 광고 글이 된다
- **제휴 표시를 적는다.** 「이 링크로 구매 시 일정 수수료를 받습니다」
  → 숨기면 신고 대상이고, 밝히면 오히려 신뢰가 올라간다
- **내가 안 써 본 것은 안 건다.** 한 번 틀리면 블로그 전체가 날아간다

**④ 가격을 적을 때** — 날짜를 같이 적는다
> 「※ 본 내용은 공식몰 공개 상품정보(2026-10-18) 기준이며, 가격과 구성은 변경될 수 있습니다.」

## 전환이 잘 되는 글의 공통점

24편을 올려 보고 광고 데이터와 맞춰 본 결과:

**직업·상황이 분명한 글**이 압도적이다.

> 「간호사핸드크림」 — 노출 105회에 클릭 16회, **클릭률 15%** (평균 0.7%의 20배)

「핸드크림 고르는 법」보다 **「간호사 핸드크림」**이 스무 배 낫다.
읽는 사람이 **자기 이야기**라고 느끼기 때문이다.

→ 글감을 고를 때 **「누구의 이야기인가」를 먼저 정한다.**

# 5. 쓰기 전 · 올리기 전 점검표

## 쓰기 전

- [ ] 0장의 다섯 줄을 채웠나
- [ ] 이 글이 깨는 오해가 한 줄로 말해지나
- [ ] 읽고 나서 오늘 할 수 있는 것이 있나

## 올리기 전

- [ ] 제목 25~40자, 검색어가 앞에 있나
- [ ] 소제목이 **질문**이고, 바로 밑 첫 문장이 **답**인가
- [ ] 본문 1,700자 넘나
- [ ] 이미지 5장 이상, 소제목마다 있나
- [ ] 썸네일이 **240px로 줄여도 읽히나**
- [ ] 내부 링크가 **진짜 글 주소**인가
- [ ] 과장어(최고·1위·무조건)·의료어(치료·효능·질환) 없나
- [ ] 마크다운 기호(`##` `**`)가 본문에 남지 않았나
- [ ] 수익 링크가 글의 70% 뒤에 있나, 제휴면 표시했나
- [ ] 예약 시각이 6:30 또는 16:30 인가

# 덧 — 가장 많이 틀린 것

**「적어 뒀나」와 「되나」는 다르다.**

이미지를 폴더에 넣어 뒀다고 글에 들어간 게 아니고,
링크를 적었다고 그 글로 가는 게 아니고,
저장을 눌렀다고 사이트에 반영된 게 아니다.

**올린 뒤에 열어서 눈으로 본다.** 이것 하나가 제일 많은 사고를 막는다.
