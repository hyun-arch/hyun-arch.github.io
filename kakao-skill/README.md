# 아람휴비스 카카오톡 상담봇 — 오픈빌더 스킬 서버

카카오톡 채널 1:1 대화에서 고객 질문에 답합니다. 사이트의 아람봇(`/arambot`) 지식을 그대로 씁니다.

```
고객 → 카카오톡 채널 → 오픈빌더 → 이 서버 → (지식 또는 모델) → 말풍선
```

## 5초 문제를 어떻게 넘겼나

카카오는 **5초** 안에 답을 못 받으면 끊습니다. 모델은 그보다 느립니다. 그래서 두 갈래로 갑니다.

| 질문 | 경로 | 걸리는 시간 |
|---|---|---|
| 아는 질문 (회사·제품·릴라이·도입·주문) | 지식에서 바로 | 0.1초 |
| 막아야 할 질문 (효능·사진·가격·내부수치) | 즉시 차단 후 담당자 안내 | 0.1초 |
| 모르는 질문 | "확인 중" 먼저 → 콜백으로 진짜 답 | 제한 없음 |

대부분의 문의는 첫 두 줄에서 끝나므로 콜백까지 가는 경우가 많지 않습니다.

## 아람휴비스라서 막아둔 것

진단기기 회사이기 때문에 일반 챗봇과 다르게 **처음부터 막아둔 영역**이 있습니다.

- **효능·상태 판단 금지** — "탈모인가요" "효과 있나요" 에 답하면 의료기기법·광고심의 문제가 됩니다. 담당자로 넘깁니다.
- **사진 안 받음** — 두피 사진은 민감한 개인정보입니다. 받는 순간 보관·파기 책임이 생기고 외부 모델로 넘어가면 더 커집니다. 매장 안내로 돌립니다.
- **가격·견적 비공개** — 환경마다 달라 담당자가 안내합니다.
- **내부 수치 비공개** — 매출·실적·연봉 등.

모델이 답을 만든 뒤에도 금지 표현이 섞였는지 한 번 더 걸러냅니다(`lib/guard.js` 의 `sanitize`).

## 올리기

```bash
cd kakao-skill
npx vercel --prod
```

환경변수(Vercel 대시보드 → Settings → Environment Variables)

| 이름 | 필요 | 설명 |
|---|---|---|
| `GEMINI_API_KEY` | 선택 | 없으면 지식 응답만 하고 모르는 질문은 담당자 안내 |
| `GEMINI_MODEL` | 선택 | 기본 `gemini-2.0-flash` |

## 오픈빌더에 붙이기

1. 카카오 비즈니스 → 톡채널 만들기(또는 기존 채널 확인)
2. [오픈빌더](https://i.kakao.com) → 봇 만들기 → 채널 연결 (**사업자번호 필요**)
3. 스킬 → 새 스킬 → URL 에 `https://<배포주소>/api/skill`
4. 시나리오 블록에 그 스킬 연결 + **콜백 사용 켜기**
5. **배포 상태에서 테스트** — 봇테스트 창은 콜백을 완전히 지원하지 않습니다
6. 폴백 블록도 같은 스킬로 연결 (모르는 질문이 흘러오게)

## 먼저 돌려 보기

```bash
node kakao-skill/serve.mjs
curl -s localhost:8787/api/health
curl -s -X POST localhost:8787/api/skill -H 'Content-Type: application/json' \
  -d '{"userRequest":{"utterance":"릴라이가 뭐예요?","user":{"id":"t"},"callbackUrl":""}}'
npm test     # 10가지 질문으로 가드레일까지 한 번에 확인
```
