5대 자동화 모듈

A 🎙️

음성 인테이크

회의·컨콜·보이스덤프를 AI가 받아 요약·핵심·액션·인사이트로 자동 정리. 모든 것의 시작점.

B 💼

세일즈 코어텍스

Salesforce식 회사별 카드. 대화→소개서→샘플/견적→테스트→구매수량→AI서버 구독($19)→기기 대수→LTV. 1→10→50→1000개사.

C 🛠️

AS 자동화

정지욱 팀장 대응지식 축적. 고객 단계별 이슈에 AI 봇·이메일·동영상으로 즉시 안내.

D 📣

마케팅 자동화

이메일·카톡·메시지 자동 발송 + 블로그·SNS 동영상 자동 발행 → 자동 판매.

E 🏭

ERP·생산·재고

맞춤화장품 자재 구매·재고·생산·폐기 오차 0·낭비 0. ERP↔생산↔재고↔판매↔마케팅 전부 연동.

3 · 협업·문화 레이어 — 어디서 만드나

혼자가 아니라 "다 같이, 다 보이게"

① 다 같이모든 사람의 아이디어·작업물이 재료
② 게임처럼생각이 오가고, 보고 배우고 다시 얹는다
③ 다 보이게과정·결과가 서로에게 보인다. 숨은 진행 없음
④ 한 곳에서개인계정 X. 회사(info)계정 > 팀방 > 프로젝트
개인 계정에서 혼자 = 일하지 않는 것 → 벌(패널티) → 한 곳에서 같이·공유하며 일하는 것이 문화로 장착 = 회사의 근간
